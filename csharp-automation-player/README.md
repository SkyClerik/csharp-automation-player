# C# Script Automation Player

Легковесный кроссплатформенный (Windows / Linux) рантайм-плеер для мгновенного выполнения сценариев автоматизации на языке C# Scripting (`.csx`) с нативным графическим интерфейсом на базе движка **Sciter**.

## 🚀 Основные особенности проекта

* **Roslyn Scripting «на лету»**: Код компилируется динамически с помощью `Microsoft.CodeAnalysis.CSharp.Scripting`. Никаких временных файлов на диске и тяжелых сборок — только чистая скорость выполнения.
* **Кроссплатформенный UI**: В качестве графического слоя используется Sciter (HTML/CSS-рендеринг). Приложение весит всего несколько мегабайт и одинаково работает как на Windows, так и на Linux.
* **Мультипроцессная архитектура (Изоляция)**: Каждый `.csx` скрипт запускается в собственной изолированной копии процесса плеера. Падение, зависание или ошибка компиляции одного скрипта никак не влияют на другие параллельно работающие сценарии.
* **CLI Инсталлятор (Без мусора в реестре)**: Запуск плеера без параметров открывает интерактивное меню, позволяющее установить или полностью зачистить ассоциации файлов `.csx` в ОС, динамически привязываясь к текущему пути EXE.
* **Делегирование подсветки синтаксиса**: Для исключения раздувания дистрибутива, написание кода и подсветка делегированы внешним IDE (VS Code, VSCodium, Zed) через механизмы ассоциации файлов.

## 🛠️ Архитектура и стек технологий

* **Backend**: .NET 8 (C#)
* **Scripting Engine**: Roslyn C# Scripting API (с поддержкой современных языковых конструкций)
* **Frontend/UI**: Sciter Engine (HTML/CSS) через обертку `EmptyFlow.SciterAPI`
* **OS Integration**: Native Win32 API / Linux CLI (`zenity`) для диалогов и менеджмента процессов.

## 📦 Интеграция и запуск

Плеер поддерживает два режима работы:

1. **Режим интеграции (Без аргументов)**: При обычном двойном клике на `SciterPlayerCSharp.exe` запускается CLI-меню управления. Нажмите `1` для чистой регистрации расширения `.csx` в системе.
2. **Режим плеера (С аргументом)**: После интеграции, клик правой кнопкой мыши по любому `.csx` файлу в системе -> *"Запустить в C# Плеере"* автоматически передает путь к файлу в `args`, компилирует и выводит UI.

### Минимальный рабочий пример скрипта (`script.csx`):

```csharp
using System;
using System.Runtime.InteropServices;

// 1. Инициализируем UI верстку прямо из кода скрипта
Api.LoadHtml(@"
<html>
<body style='background:#222; color:#fff; font-family:sans-serif; text-align:center; padding:30px;'>
    <h1 id='title'>C# Automation</h1>
    <button id='btn-calc' style='padding:10px 20px;'>Запустить калькулятор</button>
    <button id='btn-close' style='padding:10px 20px;'>Выход</button>
</body>
</html>
");

// 2. Логика для кнопки запуска калькулятора (Windows / Linux)
Api.On("btn-calc", () => {
    Api.SetHtml("#title", "Запуск процесса...");
    
    if (RuntimeInformation.IsOSPlatform(OSPlatform.Windows))
    {
        Api.RunProcess("calc.exe");
    }
    else if (RuntimeInformation.IsOSPlatform(OSPlatform.Linux))
    {
        try { Api.RunProcess("gnome-calculator"); }
        catch { try { Api.RunProcess("xcalc"); } catch { } }
    }
});

// 3. Логика для кнопки закрытия приложения
Api.On("btn-close", () => {
    Environment.Exit(0);
});
```
