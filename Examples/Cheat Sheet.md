## 📑 Справочник разработчика: C# Automation Player (Sciter + Roslyn)## 🏗️ 1. Архитектура и Жизненный Цикл
Приложение разделено на Хост-плеер (ваше скомпилированное C# .NET Core x64 приложение) и Пользовательский скрипт (.csx + HTML/CSS фронтенд).

   1. Запуск из Проводника: Контекстное меню Windows передает полный путь к вашему .csx файлу в массив args метода Main.
   2. Изоляция путей: Метод LoadHtmlLayout автоматически вычисляет папку запускаемого скрипта (scriptDir). Все относительные пути к фронтенду (ui.html, style.css) плеер ищет в папке самого скрипта, а не там, где лежит .exe плеера.
   3. Очередь выполнения: Сначала Roslyn компилирует и выполняет код .csx (заполняя настройки в объекте Api), и только после этого движок Sciter инициализирует и отображает окно интерфейса. Если в C# коде скрипта есть синтаксическая ошибка, выполнение прервется до инициализации UI.

## 🛠️ 2. Спецификация AppApi (Интерфейс Api в скриптах)
Внутри пользовательских .csx скриптов глобальный объект Api предоставляет следующий набор методов для связи C# с движком Sciter и операционной системой.
## 📺 Взаимодействие с UI (Sciter)

* void LoadHtml(string pathOrHtml)
Передает HTML-разметку для отображения окна.
* Пример: Api.LoadHtml("ui.html"); (автоматически прочитает файл из папки скрипта) или Api.LoadHtml("<html><body>Привет!</body></html>");.
* void SetHtml(string cssSelector, string html)
Заменяет внутреннее HTML-содержимое элемента, найденного по CSS-селектору.
* Пример: Api.SetHtml("#project-list", "<div class='item'>Новый проект</div>");
* string GetValue(string cssSelector)
Считывает значение из текстовых полей ввода (input, textarea) или текстовое содержимое обычных тегов.
* Пример: string path = Api.GetValue("#project-path-input");
* void SetValue(string cssSelector, string value)
Динамически устанавливает значение (атрибут value или text) для элемента на фронтенде.
* Пример: Api.SetValue("#project-path-input", "C:\\UnityProjects\\MyGame");

## 🔔 Системные диалоги и процессы (Кроссплатформенные Win32/Linux)

* void On(string eventName, Action callback)
Регистрирует обработчик события (например, клика) по ID элемента в HTML.
* Важно: Работает стабильно только со статическими ID, объявленными в HTML изначально. Из-за особенностей замыканий Roslyn в рантайме, динамическая подписка кнопок в циклах C# (например, "btn-" + index) затирает контекст. Архитектура требует «WinForms-стиля»: статические кнопки управляют динамическим контентом.
   * Пример: Api.On("btn-launch", () => { /* логика */ });
* string SelectFile(string filter = "All Files|*.*", string title = "Выберите файл")
Открывает нативное окно выбора файла через comdlg32.dll (исправлено под x64 через Marshal.AllocHGlobal). Возвращает полный путь к файлу или пустую строку, если выбор отменен.
* Пример: string file = Api.SelectFile("Проекты|*.txt;*.json", "Выберите конфиг");
* string SelectFolder(string title = "Выберите папку")
Открывает нативное окно выбора директории через shell32.dll. Возвращает полный путь к выбранной папке.
* Пример: string folder = Api.SelectFolder("Выберите корень проекта Unity");
* void Alert(string message, string title = "Уведомление")
Выводит стандартное системное модальное окно с сообщением и кнопкой «ОК».
* Пример: Api.Alert("Редактор Unity не найден!", "Ошибка");
* bool Confirm(string message, string title = "Подтверждение")
Выводит системное окно с вопросом и кнопками «Да»/«Нет». Возвращает true, если пользователь согласился.
* Пример: if (Api.Confirm("Очистить кэш проектов?", "Вы уверены?")) { /* очистка */ }
* void RunProcess(string filename)
Запускает системный процесс (программу, скрипт или файл через ассоциации ОС). Принимает строго один строковый аргумент. Флаги запуска нужно склеивать прямо в строку вызова вместе с путями.
* Пример: Api.RunProcess("\"C:\\Program Files\\Unity\\Editor\\Unity.exe\" -projectPath \"D:\\MyGame\"");

## 🗂️ Модуль Нативного Drag-and-Drop Папок (Win32 Core)

* void EnableDragDrop(string cssSelector, Action<string> onDropCallback)
Активирует нативную Win32-поддержку перетаскивания папок из Проводника Windows или OneCommander напрямую в окно лаунчера [INDEX]. Метод перехватывает низкоуровневые сообщения WM_DROPFILES (код 0x0233) на самом входе в приложение, полностью обходя любые внутренние C++ блокировки безопасности и ограничения движка Sciter 6 [INDEX].
* Архитектурное требование: Чтобы исключить привязку хука к пустому указателю окна (HWND = 0), вызов Api.EnableDragDrop необходимо оборачивать во встроенный метод ожидания готовности окна Api.On("hidden-init-btn", ...) [INDEX][INDEX]. Сигнал hidden-init-btn генерируется C# хостом плеера автоматически через 100 мс после фактического создания окна в операционной системе Windows [INDEX].
   * Параметры:
   * cssSelector — строка с ID или классом целевого элемента (например, "#drop-zone").
      * onDropCallback — C# метод или лямбда-выражение (path) => { ... }, принимающее строку чистого пути к сброшенной папке.
   * Пример использования в .csx:
   
   Api.LoadHtml("drag_drop.html");
   // Запускаем хук СТРОГО в момент фактической готовности HWND окна
   Api.On("hidden-init-btn", () => {
       Api.EnableDragDrop("#drop-zone", (path) => { 
           Api.SetValue("#folder-path", path);
           Console.WriteLine("Папка успешно сброшена в C#: " + path);
       });
   });

## 🚫 3. Ограничения Рослина (Чего делать нельзя)

   1. Динамические ссылки на сборки: Контекст компиляции скриптов Roslyn внутри метода ExecuteUserScriptAsync жестко ограничен массивом requiredAssemblies. По умолчанию скрипт не видит тяжелые UI-библиотеки хоста (вроде System.Windows.Forms или WPF). Все диалоги и уведомления нужно вызывать исключительно через методы Api.
   2. Модификация DOM «на лету»: Избегайте генерации сложных интерактивных элементов через Api.SetHtml(), если на них планируется вешать новые обработчики кликов. Намного надежнее сделать статические элементы в HTML и менять их видимость (display: none/block) или обновлять их текстовые значения через Api.SetValue.
   3. Защита от рекурсии чтения (StackOverflowException): Монолитный Win32-хук плеера снабжен автоматической защитой от повторной регистрации оконной процедуры. Полученный из коллбэка путь к папке path запрещено асинхронно перечитывать методом Api.GetValue() во время выполнения логики — значение необходимо использовать напрямую из аргумента лямбды [INDEX].
